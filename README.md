# מיפוי ארגוני צעירים – גליל מזרחי ומערבי

דשבורד אינטראקטיבי של ארגונים, תוכניות וגופים שפועלים בתחום הצעירים בגליל, מטעם מרכז הידע האזורי.

> המאגר כולל רק מידע ציבורי על הארגונים. **אין בו פרטי קשר אישיים** (שמות אנשי קשר או מספרי טלפון).

## מבנה המאגר

| קובץ | תיאור |
|---|---|
| `index.html` | הדשבורד. קובץ עצמאי שהנתונים מוטמעים בתוכו. עובד גם בפתיחה ישירה מהדיסק, בלי שרת |
| `assets/logo.png` | הלוגו שמוצג בדשבורד |
| `data/organizations.json` | **מקור האמת לנתונים.** זה הקובץ שסוכן AI או מערכת חיצונית צריכים לקרוא |
| `scripts/build.py` | מעתיק את הנתונים מ-`data/organizations.json` אל `index.html` |

## מבנה הנתונים (`data/organizations.json`)

מערך JSON. כל רשומה מתארת ארגון או תוכנית אחת:

| שדה | סוג | משמעות |
|---|---|---|
| `name` | טקסט | שם הארגון או התוכנית |
| `cats` | רשימת טקסטים | תחומי פעילות, למשל `קהילה`, `תעסוקה ויזמות`, `חינוך והשכלה`, `התיישבות וציונות`, `מנהיגות`, `חירום וחוסן` |
| `locs` | רשימת טקסטים | יישובים או אזורים שבהם הארגון פועל. `רחבי הגליל` מציין פעילות אזורית כללית |
| `desc` | טקסט | תחום הפעילות ותיאור הפרויקטים. יכול לכלול שורות חדשות (`\n`) |
| `target` | טקסט | אוכלוסיית היעד או מידע משלים. ריק כשאין מידע |

דוגמה:

```json
{
  "name": "מיזם מעלה",
  "cats": ["מנהיגות"],
  "locs": ["רחבי הגליל"],
  "desc": "ליווי רשויות ונתינת כלים מקצועיים לפיתוח תחום הצעירים...",
  "target": ""
}
```

## שילוב במערכת חיצונית

- **הצגת הדשבורד:** מגישים את `index.html` יחד עם התיקייה `assets/`, או מטמיעים אותו ב-iframe. אין צורך בשרת או בקריאות API.
- **גישה של סוכן AI לנתונים:** מספיק לתת לסוכן את `data/organizations.json`. הקובץ כולל את כל מה שמוצג בדשבורד, במבנה מובנה.
- יש לעבוד מול הענף `main`.

## עדכון הנתונים

1. עורכים את `data/organizations.json`.
2. מריצים `python3 scripts/build.py` כדי לעדכן את `index.html`.
3. מוודאים שהקבצים מסונכרנים בעזרת `python3 scripts/build.py --check`.

אין לערוך ישירות את הנתונים בתוך `index.html`, בין הסימונים `DATA:START` ו-`DATA:END`, כי ההרצה הבאה של הסקריפט תדרוס את השינויים.

**אין להוסיף למאגר פרטי קשר אישיים או קובצי אקסל מקוריים שיש בהם פרטים כאלה.**
